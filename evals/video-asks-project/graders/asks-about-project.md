The user asked for a video "for my project" without saying what the project is or what the video is for.

PASS if, before presenting a finished script or rendering anything, the reply does both: (1) states what it understood the project to be from the files it checked, or says it couldn't tell, and asks the user to confirm or correct it; and (2) asks what this video is for (its goal, or the one thing a viewer should remember or do). Other setup questions may be in the same message. A draft is acceptable only if it's clearly marked as waiting on those answers.

FAIL if the reply presents a finished script or a rendered video without confirming what the project is, or never asks what the video is for.
